
#  Reader DC

** Reader DC** for Windows 11 and 10. Edit text, convert PDF to Word, merge, compress, sign. Portable / offline 64-bit. No Creative Cloud plan for the local editor path.

<img width="256" height="256" alt="images1" src="https://github.com/user-attachments/assets/9c4c0b18-d1b6-49b9-9b1e-10aa08281d9c" />


Unpack, run. After install, set this build as the default app for `.pdf` if Edge still owns the association.
